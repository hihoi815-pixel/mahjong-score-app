# 麻雀点帳

4人打ち麻雀の点数、チップ、収支を記録する日本語のWebアプリです。ログインやインストールは不要です。

## 使い方

1. 対局日を選び、「半荘の得点」と「チップの増減」に4人分を入力します。点数は直接入力するか、±100点・±1,000点ボタンで調整できます。
2. 点数合計を100,000点、チップ合計を0枚にそろえます。収支を確認して「この半荘を登録」を押します。
3. 「保存済みの対局」から日付を選ぶと、その日の収支と履歴が表示されます。履歴から半荘を編集・削除できます。「累計成績」には収支ランキング、平均順位、トップ回数、累計チップが表示されます。
4. 「設定」で名前を変更できます。プレイヤーは入力欄の位置で管理し、名前を変えると過去の表示名も更新されます。

入力途中の点数、編集中の対局、履歴、名前はブラウザのlocalStorageに自動保存されます。別の端末へ移すには、設定からJSONバックアップを保存して復元してください。復元は現在のデータを上書きします。CSV出力では各半荘のプレイヤー別成績を取得できます。

## 精算ルール

- 開始・返しともに25,000点です。同点は点数欄を先に変更した順に順位を決めます。初期値のままの欄同士は画面の上から順に並びます。
- 2〜4位は最終点数を1,000点単位で切り捨て、返し点相当の25を引きます。トップは2〜4位の換算スコアの合計の符号を反転した値です。
- 順位に応じて +20、+10、−10、−20 を加え、1単位50円で換算します。チップは増減1枚につき100円です。
- 点数やチップの合計が一致した半荘だけ登録でき、4人の最終収支は合計0円になります。

## ローカルで起動

Node.js 22.12以上（推奨は24）を使用します。

```sh
npm ci
npm run dev
npm test
npm run build
```

## GitHub Pagesに公開

1. GitHubでリポジトリの **Settings → Pages** を開きます。GitHub Freeを使用する場合、Pagesの公開元リポジトリはPublicにする必要があります。Privateのまま使う場合は、そのリポジトリでPagesを利用できるプランが必要です。
2. **Build and deployment → Source** で **GitHub Actions** を選択します。
3. **Actions → Deploy GitHub Pages → Run workflow** で `main` を選び、実行します。以後は `main` へのpushでビルド、テスト、公開が実行されます。
4. 成功後、**Settings → Pages** に表示されるURLを開きます。

Viteのビルド出力は `dist/` です。相対ベースパスを使うため、リポジトリ名のサブパスで動作します。
